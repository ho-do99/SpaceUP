# 도면 분석·3D 연결 안내

## 이번 작업

- Object Storage에서 받은 PNG/JPEG를 AI 분석 서비스에 올바른 multipart Content-Type으로 전달합니다.
- AI가 반환한 방 이름·면적·polygon·bbox 원본 결과를 분석 건에 저장합니다.
- 참여자만 저장된 시각화 결과를 조회할 수 있는 API를 추가합니다.
- 공간 정보 화면에 `원본` / `3D 분석` 탭을 추가합니다.
- 3D 탭은 필요할 때만 로드하며 회전·확대가 가능합니다. polygon이 없으면 bbox로 대체합니다.
- 처리 제한시간을 백엔드 300초, nginx 330초, 프론트 360초로 맞춥니다.

## 배포 시 확인

1. Flyway가 `V7__floorplan_visualization_json.sql`을 적용했는지 확인합니다.
2. 주소 검색 후 매핑된 도면을 선택하고 분석을 실행합니다.
3. 공간 정보 화면에서 방 목록과 면적이 표시되는지 확인합니다.
4. `3D 분석` 탭을 눌러 공간 형태가 표시되고 회전·확대되는지 확인합니다.
5. 기존 분석 건에는 시각화 JSON이 없으므로 필요하면 도면 재분석을 실행합니다.

## 다음 작업 권장 순서

1. 실제 운영 도면 4종으로 polygon·bbox 품질과 방 이름 매칭을 검증합니다.
2. AI 응답 스키마 버전을 추가하고 잘못된 좌표·과도한 payload를 서버에서 제한합니다.
3. 3D 공간 선택, 방별 높이 수정, 문·창문·가구 배치 기능을 단계적으로 연결합니다.
4. Three.js 번들 크기와 저사양 모바일 FPS를 측정해 메시 단순화 및 캐시를 적용합니다.
5. `ai` CI 성공 후 `develop` 병합, 통합 CI 성공 후에만 `main` 반영 및 배포 승인을 진행합니다.
