# 인테리어 시뮬레이션·자재 추천 연결 안내

## 연결된 사용자 흐름

1. 인테리어 스타일 선택
2. 현재 집 사진 JPG/PNG 업로드 및 의뢰 사진 연결
3. Gemini 기반 AI 인테리어 이미지 생성과 생성 상태 조회
4. Before/After 시뮬레이션 결과 비교
5. 도면 분석 면적과 선택 스타일 기반 자재 추천
6. 바닥재·벽지·조명 카탈로그 비교 및 선택
7. 선택 테마와 자재 제품 ID 3개를 의뢰에 저장
8. 저장 성공 후 시공사 선택 화면으로 이동

## 변경 사항

- 자재 추천 화면이 일반 카탈로그의 첫 항목 대신 `recommended-products` API를 사용합니다.
- 추천 요청에 사용자가 고른 `MODERN`, `WOOD`, `WHITE`, `MARBLE` 테마를 전달합니다.
- 바닥·벽 면적으로 계산된 추천 수량, 금액, 추천 이유를 화면에 표시합니다.
- 총 예상 비용은 추천 자재 금액 합계의 ±10% 범위로 표시합니다.
- 최종 버튼은 `PATCH /api/requests/{requestId}` 저장 성공 후에만 다음 화면으로 이동합니다.
- 저장 실패 시 현재 화면을 유지하고 재시도 가능한 오류를 표시합니다.

## 다른 PC에서 이어서 확인

1. `git switch ai`
2. `git pull --ff-only origin ai`
3. 프론트·백엔드 환경변수를 준비합니다. AI 이미지 생성에는 `GEMINI_API_KEY`가 필요합니다.
4. 주소 검색부터 도면 분석을 완료한 후 스타일 선택 흐름을 진행합니다.
5. 자재 추천 화면에서 스타일명, 분석 기반 수량·이유·금액을 확인합니다.
6. 최종 선택 후 의뢰 상세 응답 또는 DB에서 선택 테마·제품 ID를 확인합니다.
