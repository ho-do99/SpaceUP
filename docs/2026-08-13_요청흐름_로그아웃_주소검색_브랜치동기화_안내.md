# 2026-08-13 요청 흐름·로그아웃·주소 검색 수정 안내

## 팀 공유 요약

이번 변경은 사용자 화면에서 발생한 두 종류의 HTTP 409, 시공사 계정설정 로그아웃 비활성화, 등록 평면도가 있는 아파트만 검색되는 문제를 수정한다.

### 1. 아파트·빌라 다음 단계 HTTP 409

원인은 `POST /api/requests`와 프론트의 분석 시작 API가 각각 `analysis_job`을 생성한 것이었다. `analysis_job.request_id`는 UNIQUE이므로 두 번째 생성이 409로 실패했다.

수정 계약:

- `POST /api/requests`: 의뢰만 생성
- 평면도 선택 또는 업로드 완료 후 `POST /api/analysis/request/{requestId}` 호출
- 같은 요청으로 분석 시작 API를 재호출하면 기존 `analysisJobId` 반환
- 동시 호출은 의뢰 행 잠금으로 직렬화
- DB UNIQUE 제약 유지

### 2. 시공사 로그아웃

- 계정설정 화면의 비활성 로그아웃 버튼 활성화
- 설정 화면과 계정설정 화면이 공용 확인 다이얼로그 사용
- 확인 시 인증 세션과 진행 중 요청 흐름 제거
- 취소 시 세션 유지

### 3. 아파트 주소 검색

기존 검색은 SpaceUP 평면도 카탈로그만 조회했기 때문에 카탈로그에 등록된 아파트만 결과로 표시됐다.

변경 흐름:

```text
검색어 입력 → Kakao 공식 주소 검색 → 주소 선택
  ├─ SpaceUP 등록 평면도 있음 → 면적 선택 → 등록 도면 AI 분석
  └─ SpaceUP 등록 평면도 없음 → 면적 직접 입력 → 평면도 업로드 → AI 분석
```

Kakao 우편번호 서비스는 별도 API 키 없이 사용한다. 선택된 공식 주소의 건물명 또는 도로명주소로 SpaceUP 평면도 카탈로그를 후속 조회한다.

## 팀원 확인 사항

- `main` 반영 후 각 담당 브랜치는 같은 커밋으로 fast-forward 동기화된다.
- 개인 작업이 남아 있는 로컬 브랜치에서는 바로 `pull`하지 말고 먼저 커밋하거나 임시 보관한다.
- 동기화 후 작업 시작 전 `git pull --ff-only origin <브랜치명>`을 사용한다.
- 운영 환경에 `JUSO_API_KEY`를 추가할 필요가 없다.
- 운영 배포 후 실제 `CONTRACTOR` 계정으로 로그아웃을 수동 확인한다.
- 운영 배포 후 아파트 등록 도면, 아파트 미등록 도면, 빌라 직접 업로드 세 흐름을 각각 확인한다.
